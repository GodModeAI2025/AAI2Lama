How It Works

AAI2Lama bridges the gap between Apple Intelligence and the tools you already use.

Ollama CLI / Open WebUI / OpenAI SDK / Any Client | +---------v----------+ | AAI2Lama | :11434 (proxy) or :11435 | Hummingbird 2 | +----+----------+----+ | | model=apple | | other models -intelligence | | | | +--------v--+ +----v-----------+ | Foundation | | Real Ollama | | Models | | :11436 | | (on-device)| | (llama3, etc.) | +------------+ +----------------+

Good to Know

macOS 26+ Only

Requires Apple Silicon and macOS Tahoe with Apple Intelligence enabled.

~4K Context Window

Smaller than typical LLMs. Long conversations are auto-truncated, keeping recent messages.

Text Only

No image or multimodal input. The Foundation Models API is text-in, text-out.

On-Device ~3B Model

Fast and private, but smaller than cloud models. Great for quick tasks, summaries, and local tooling.
